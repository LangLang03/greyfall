# Schema 2 兼容夹具

`schema2-mechanics.bin` 是修改前的 schema 2 程序通过 `serializeState` 生成的二进制状态载荷，不是加密 `.gsv` 文件。它用来确保新增字段不会让旧格式读取错位。

生成时从默认 `GameState` 开始，设置：

- `tick = 17`。
- 一个 `eventId = 55` 的待抉择事件，选项为旧版派系生成器的“满足诉求（消耗资源，满意度 +25%）”“压制派系（民怨 +，满意度 -）”“拖延（压力继续累积）”。
- 一个 `qty = 5`、`term = 2`、`openedTick = 15` 的期货头寸。

夹具必须保留为旧版程序生成的字节；不要用当前序列化器覆盖，否则迁移测试将不再覆盖旧格式。
